## Research basis

The skill synthesizes README design principles from:
- GitHub's README guidance and repository-health model;
- the distinction between README onboarding and agent-operational instructions;
- observed public README patterns across mature developer tools, frameworks,
  applications, monorepos, and knowledge repositories;
- Agents-DevKits' own bounded-ownership and evidence-first conventions.

## Local adaptation

The local adaptation converts those observations into a project-adaptive workflow:
repository inspection → evidence model → audience/job definition → conditional
section architecture → authoring → verification.

No external repository's README or prompt text is copied as a template.
