# Interface-copy checklist

Check that each line:

- names the action or result in language the target user understands;
- matches the emotional context without sounding evasive or blaming;
- gives errors a recovery action and empty states a useful first action;
- uses a visible label when an input needs one;
- does not rely only on color, position, or iconography for meaning;
- is translatable without word-order assumptions or string concatenation;
- respects supplied character limits and approved terminology.

For destructive actions, the confirmation control should restate the action and object clearly.
