# Optional unattended decision trail

Use only for long-running, unattended, multi-phase, or safely parallel work
where a reviewer must reconstruct material decisions. Keep a small append-only
execution scratch record with time, work unit, decision, why, evidence pointer,
and result. An evidence pointer may be a commit, file and line, retained command
output, screenshot, trace, or PR.

This is not a roadmap, ADR, project memory, issue tracker, permanent telemetry,
or chain-of-thought record. Promote durable accepted facts to the project's
existing canonical owner, then retain or discard the scratch record under
project policy.
