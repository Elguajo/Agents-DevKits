# Optional independent adversarial code review

Use only for an explicit request or a project-specific requirement, and only
when independent reviewers are actually available. Ordinary `code-review`
remains the default.

Before sharing private repository material with an external model or service,
obtain explicit authorization. Do not claim self-review is independent review.

Give each reviewer the same intended behavior, diff/artifact, relevant context,
and rubric. Do not invent role-play diversity. The lead verifies important
findings against the repository, deduplicates them, marks consensus versus lone
findings, surfaces disagreements, and applies the normal severity/evidence
contract. Reviewer output is evidence, not truth. Do not apply fixes
automatically.
