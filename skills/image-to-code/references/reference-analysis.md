# Reference-analysis checklist

Capture observations before implementation:

- content hierarchy and page regions;
- layout grid, alignment, density, and breakpoints implied by the image;
- type roles, spacing rhythm, surfaces, borders, radius, and elevation;
- reusable controls and their observable states;
- assets that are project-provided, licensed, unknown, or must be replaced;
- assumptions that require a separate decision.

A screenshot proves only visible output at one state and viewport. It does not prove responsive, semantic, keyboard, loading, error, or empty-state behavior.
