# Reference-Guided UX Improvement

Use references to answer **how other mature products solve the same user problem**, not “what visual style should we copy?”

## Reference order
Prefer, when available:
1. production products solving the same task;
2. adjacent products with the same interaction pattern;
3. established platform/design-system guidance;
4. credible UX research or benchmark evidence;
5. curated real-product flow libraries.

Concept-only showcase work can inspire visual direction, but should not be treated as evidence of usable interaction.

## For each useful reference capture
- the user problem being solved;
- the relevant flow or interaction pattern;
- what makes the pattern understandable/efficient;
- assumptions or product context that differ from the current project;
- what is worth adapting;
- what should **not** be copied.

## Rules
- Do not copy branding, visual identity, or proprietary content.
- Do not recommend a pattern solely because a famous product uses it.
- Do not introduce a new pattern when the current design already solves the problem clearly.
- Prefer multiple references for major changes rather than anchoring on one product.
- When evidence conflicts, explain the trade-off rather than pretending there is one universal answer.
