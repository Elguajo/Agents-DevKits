# Apple-Quality Benchmark

Apple's Human Interface Guidelines are used here as a decision framework for
quality, not as a visual template. The output of this benchmark is a judgement
about the current product, expressed in the product's own language.

## Benchmark questions

**Purpose** — Can a first-time user tell what this screen is for within a few
seconds? Is the most important thing also the most prominent thing?

**Agency** — Is the person informed about what will happen, in control of when
it happens, and able to undo or recover? Are destructive actions distinguishable
from ordinary ones?

**Responsibility** — Does the interface avoid trading clarity, safety, privacy,
accessibility, or responsiveness for visual novelty?

**Familiarity** — Are standard controls used for standard jobs? Does the same
concept look and behave the same way in every place it appears?

**Flexibility** — Does the experience survive a different viewport, input mode,
text size, language length, or content volume?

**Simplicity** — Has unnecessary complexity been removed without hiding
capability that people actually need? Emptiness is not simplicity.

**Craft** — Do alignment, optical balance, proportion, and state coverage look
deliberate at close inspection?

**Delight** — Does character and feedback support the task rather than compete
with it, especially on repeated actions?

## Platform weighting

- For an actual Apple-platform application, platform conventions and controls
  carry stronger weight, and deviating from them needs justification.
- For a web product, web conventions and the existing product identity win.
  Do not import Apple-specific controls, materials, token values, or platform
  behavior in order to look like Apple.

## What this benchmark never authorizes
- copying Apple layouts, marketing composition, typography licensing, or branding;
- translucency, heavy blur, or oversized radii applied because Apple uses them;
- replacing a working product identity with a generic premium look;
- claiming an accessibility or performance result that was not tested.
