# Solution Challenge / Alternative Architecture Review
## Goal
Determine whether the proposed solution is the simplest robust approach to the real requirement.

## Workflow
1. Restate the actual requirement and constraints.
2. Inspect enough of the existing architecture to judge fit.
3. Generate 2–3 genuinely viable approaches only when they materially differ.
4. Compare correctness, complexity, change surface, maintainability, performance, migration cost, regression risk, and reversibility.
5. Recommend the simplest approach that satisfies the requirement.

## Rules
- Do not implement.
- Do not reward novelty.
- If the original solution is already clearly best, say so rather than inventing alternatives.

## Output
Options, trade-offs, recommendation, why alternatives lose, and open assumptions.
